SDGs yang Dipilih: Tujuan 4: Pendidikan Bermutu (Quality Education) Aplikasi ini mendukung terciptanya pendidikan yang bermutu dengan membantu pelajar meningkatkan fokus, manajemen waktu, dan kebiasaan belajar yang baik melalui pendekatan gamifikasi.

Deskripsi Singkat Aplikasi: StudyPet adalah aplikasi produktivitas berbasis Android yang menggabungkan manajemen waktu belajar dengan keseruan merawat hewan peliharaan virtual. Setiap kali pengguna menyelesaikan sesi belajar atau tugas, mereka akan mendapatkan poin atau experience (XP) untuk memberi makan, merawat, dan membesarkan peliharaan virtual mereka. Aplikasi ini dirancang untuk mengatasi rasa malas dan menumbuhkan motivasi belajar agar lebih konsisten dan menyenangkan. Fitur Utama Aplikasi: Fitur Aplikasi StudyPets

Registrasi • Membuat akun baru. • Memilih karakter pet (Kucing atau Anjing).

Login • Masuk ke dalam aplikasi menggunakan akun yang telah terdaftar.

Dashboard • Menampilkan informasi utama seperti level pet, XP, koin, quest, dan progres belajar.

Ubah Nama Pet • Mengganti nama pet sesuai keinginan pengguna.

Belajar & Quiz • Memilih materi yang ingin dipelajari. • Menonton video pembelajaran. • Setelah video selesai, pengguna langsung mengerjakan quiz. • Mendapatkan XP dan hadiah setelah menyelesaikan quiz.

Quest • Quest Pribadi: Pengguna dapat menambahkan quest sendiri sebagai pengingat, namun tidak memperoleh XP maupun koin. • Quest dari Admin: Pengguna mengerjakan quest yang dibuat oleh admin. • Setelah selesai, pengguna wajib mengunggah bukti penyelesaian quest. • Bukti akan direview oleh admin. • Jika disetujui, pengguna akan memperoleh XP dan koin sebagai hadiah.

Inventory • Menyimpan item yang dimiliki pengguna. • Digunakan untuk memberi makan dan minum pet.

Shop • Membeli makanan dan minuman untuk pet menggunakan koin yang dimiliki.

Statistik • Menampilkan riwayat aktivitas pengguna, seperti: • Materi yang telah dipelajari. • Quiz yang telah diselesaikan. • Quest yang telah selesai. • Total XP dan progres pengguna.

Kalender • Menambahkan jadwal atau deadline. • Membantu pengguna mengatur target belajar dan penyelesaian quest.

Akun Admin • Mengelola data pengguna (menghapus akun pengguna jika diperlukan). • Membuat dan mengelola quest untuk pengguna. • Mereview bukti quest yang diunggah pengguna. • Menyetujui atau menolak quest sehingga hadiah (XP dan koin) dapat diberikan.

Dark Mode • Mengubah tampilan aplikasi menjadi mode gelap untuk meningkatkan kenyamanan penggunaan.

Fitur Log Out

Cara Menjalankan Aplikasi: Untuk menjalankan source code aplikasi ini di perangkat atau emulator Anda, ikuti langkah-langkah berikut:

Clone Repository: Buka terminal atau command prompt, lalu jalankan perintah berikut: git clone https://github.com/JoyRo-n/StudyPet.git
Buka di Android Studio: Buka aplikasi Android Studio. Pilih menu File, lalu pilih Open. Cari dan pilih folder StudyPet hasil clone tadi.
Sinkronisasi Gradle: Tunggu beberapa saat hingga Android Studio selesai melakukan Sinkronisasi Gradle. Pastikan Anda terhubung ke jaringan internet.
Jalankan Aplikasi: Siapkan emulator (AVD) atau sambungkan perangkat Android fisik Anda menggunakan kabel USB (pastikan USB Debugging aktif di HP Anda). Klik tombol Run (ikon segitiga) di toolbar atas atau tekan Shift + F10.
